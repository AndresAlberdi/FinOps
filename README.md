# FinOps-Ecosistema

Optimización de costos y recursos de todo el ecosistema (Claude/Anthropic, AWS, Google Cloud y Firebase, OCI, n8n, Meta WhatsApp, GitHub y SaaS) **sin afectar funcionalidad, calidad ni seguridad**.

- Reglas de trabajo para Claude Code: `CLAUDE.md`.
- Alcance, inventario, metodología, guardarraíles y accesos: `docs/`.
- Estado: `ESTADO.md`.
- Sesión de arranque: `Prompts/arranque.md`.

Este repositorio no contiene datos de facturación ni identificadores completos: esos datos viven en `datos/`, que git ignora.

Repositorio: `git@github.com:AndresAlberdi/FinOpsEcosistema.git` (público, modo A del estándar DevSecOps v2).
